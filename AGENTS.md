# Agent platform instructions

The outer platform is the orchestrator. Read `.ai/` as project source of truth and inspect existing code before edits. Select only agents needed for the task; backend, frontend, database, qa and devops prefer local Qwen, while analyst, architect and independent reviewer use Codex CLI. Load skills lazily from the index, never execute third-party skill scripts without reviewing them. Engram notes are optional and must be checked against `.ai/` and code. Run relevant tests after implementation and obtain an independent reviewer result before workflow completion. A child analyst, architect or reviewer handles only its assigned stage; it must not launch other agents. Keep work inside the workspace. Require human approval for commits, destructive database operations, production access and deployment. Never push or force push. Never use an OpenAI API key.
